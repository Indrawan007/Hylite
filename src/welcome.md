# Welcome to Hylite ✨

A native Markdown editor for **Arch + Hyprland**.

## Features

- [x] Source mode
- [x] Live preview
- [x] Split view
- [x] Zen mode (F11)
- [ ] WYSIWYG editing

## Shortcuts

| Key            | Action          |
|----------------|-----------------|
| Ctrl+O         | Open file       |
| Ctrl+S         | Save file       |
| Ctrl+Shift+S   | Save As         |
| Ctrl+N         | New file        |
| Ctrl+B         | Toggle sidebar  |
| Ctrl+Shift+M   | Cycle mode      |
| F11            | Zen mode        |
| Esc            | Exit zen mode   |
